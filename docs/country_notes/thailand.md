# Thailand

## Resources
- ERC (Energy Regulatory Commission): `erc.or.th` — licenses LNG "shippers"; the shipper list is the main false-positive trap (see tips).
- EPPO (Energy Policy and Planning Office): `eppo.go.th` — PDP (Power Development Plan) & Gas Plan; a project's presence/absence in the draft PDP is a good dormancy signal.
- DMF (Department of Mineral Fuels): `dmf.go.th` — upstream Gulf-of-Thailand concessions (relevant only if an FLNG/associated-gas export idea ever surfaces; Thailand is a declining producer / net importer, so none as of 2026).
- Sponsors: PTT / PTT LNG (`pttlng.com`), EGAT (`egat.co.th` — note the owner ref there can 404, use Wayback), Gulf Development PCL (formerly Gulf Energy Development; `gulf.co.th`), PTT Tank.
- Trade press: LNG Prime, Offshore Energy (offshore-energy.biz), Reuters, S&P Global, Bangkok Post, The Nation Thailand; Korean press (Aju, IPP Journal) for the KOGAS/KOWEPO-linked Chana project.

## Research Tips
- **Shipper licence ≠ terminal (the dominant Thai false positive).** Since ~2021 the ERC has licensed many "LNG shippers" (Gulf LNG 6.4 mtpa first cargo Jan 2025, Hin Kong/Ratch, B.Grimm, GPSC, Siam Gas, etc.). They import *through the existing Map Ta Phut 1/2 terminals* — no new marine facility. Out of scope. The gas-fired plants they feed are GOGPT, not terminals.
- **Only 2 operating terminals, both at Map Ta Phut, Rayong:** MTP1 (PTT LNG, ~11.5 mtpa incl. Expansion) and MTP2/Nong Fab (PTT+EGAT JV "PE LNG", 7.5 mtpa). MTP3 (Gulf 70% / PTT Tank 30%, entity "Gulf MTP LNG Terminal Co Ltd" — GEM spells it "Gulf MPT", a known typo) is the only new-build in the pipeline.
- **The southern-Thailand FSRU is one moving concept across three dead records:** Songkhla FSRU (PTT, cancelled 2018) → Gulf of Thailand / Samut Prakan FSRU (EGAT, cancelled 2021) → Surat Thani FSRU (EGAT/PTT 5 mtpa, shelved). Each was explicitly *replaced* by the next, not revived — so a new southern-FSRU mention is almost always the existing Surat Thani record, not a new terminal. Chana LNG (KOGAS/KOWEPO/TPIPP, cancelled 2025) is the separate Songkhla-Chana industrial-estate project, tied to the ~1.7 GW Songkhla Chana power station.
- **"LNG-to-power" bundles feed off Map Ta Phut** (pipeline-fed), so the plant sites fail the marine-import gate — GOGPT, not new terminals.
- Parent rebrand: **Gulf Energy Development → Gulf Development PCL (2025)**.
